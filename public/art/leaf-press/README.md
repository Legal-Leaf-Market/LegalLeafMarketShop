# The Legal Leaf print drawer

Sixty original transparent vector marks, grouped in five drawers. Open print-drawer.webp for a visual index. Use the illustrations at their natural square ratio, usually 48–120 CSS pixels. Use an empty alt attribute for decorative marks. Use the artwork title as alt text when the mark communicates an item on its own. Keep the panoramic café concept paintings as lead artwork. Pair one or two little motifs with a printed note, a journal story, or a record recommendation.
