# Detroit seed list — LEADS, NOT A ROSTER.

# Every line here is a name and a url from public search. That makes each one a
# `candidate` in api/markets.js terms: "a lead. It is never fetched on the live
# path and never shown." Nothing in this file may go into api/market-stores.js
# until tools/discover-market.mjs has FETCHED it and its own page has named the
# city. That is the standard the Coldwater seven were built to and it does not
# move because the roster got bigger.
#
# THE STATE SAYS 61. Detroit's FY2025 payout was $3,295,043.10, which is 61
# licences at $54,017.10 -- arithmetic on the state's own cheque. Asked the same
# question in one sitting, directories answered 49 and 13. So this file is
# deliberately short of 61 and the gap is the honest reading: what is here is
# what could be named with a url attached, not what exists.
#
# ------------------------------------------------------------------------------
# THE DETROIT-SPECIFIC TRAP, AND IT IS WORSE HERE THAN ANYWHERE ELSE IN MICHIGAN.
#
# HAMTRAMCK and HIGHLAND PARK are separate cities completely surrounded by
# Detroit. Own councils, own ordinances, own licences, own line in the Treasury
# distribution. A shop on Caniff Street has a Detroit mailing address, shows up
# under "Detroit" on every directory, and is NOT one of Detroit's 61.
#
# This is the East Lansing lesson at closer range -- close enough that a human
# reading an address cannot tell, which is exactly why the confirm step reads the
# shop's OWN page for the city name rather than trusting the address. Same for
# the ring: Ferndale, Hazel Park, Oak Park, Dearborn, Redford, River Rouge,
# Ecorse, Lincoln Park, Melvindale, Warren, Harper Woods and the Grosse Pointes
# all sit against the city line and all sell under "Detroit" on a directory.
#
# Lines below that are known to be in an enclave or a suburb are marked and
# commented OUT, not deleted -- the `dead` state exists so the next sweep does
# not rediscover and re-add them.
# ------------------------------------------------------------------------------
