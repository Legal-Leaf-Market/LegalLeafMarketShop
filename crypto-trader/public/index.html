    Rules: the trend breaks on a daily close → sell. Disaster stop (trails up, never down) → sell. Target → sell half, stop to break-even. Horizon reached → close out. A move bigger than the coin's usual hour → "popping".

    The only top traders you can watch instead of believe.

    Hyperliquid settles every trade on-chain, so its leaderboard is a live query over real accounts, not a curated list. Ranked by 30-day profit. Tap one to see what it holds right now and its last fills. Read-only: this is a window, not a copy-trader.

    Would this have worked?

    Walks forward through the last months with the sliders above: every cycle re-runs the screen using only the days before it, buys at that close, exits by the same rules, pays the fees you chose both ways, and compounds into the next cycle. No peeking. If it says it lost, believe it over the Plan tab.
